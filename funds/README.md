# 国内基金技术分析与买卖决策助手

基于 [akshare](https://akshare.akfamily.xyz/) 拉取国内公募开放式基金的历史单位净值，
通过多种技术指标综合打分，结合资金仓位与交易记录，给出当日的买/卖/观望及具体金额建议。
提供 **图形界面（GUI）** 与 **命令行（CLI）** 两种使用方式。

## 安装

建议使用 Python 3.10 或更高版本，并在仓库根目录执行：

```bash
python -m pip install -r funds/requirements.txt
```

## 模块结构

```
funds/
├── __init__.py
├── data_fetcher.py   # akshare 获取：净值/名称/持仓/单股实时行情/基金当日估算涨跌
├── indicators.py     # MA / MACD / RSI / 布林带 / KDJ 计算
├── strategy.py       # 多指标加权评分 + 操作建议
├── storage.py        # 本地 JSON 持久化（data/ 目录）
├── watchlist.py      # 自选基金清单管理
├── trade_log.py      # 每日买卖操作记录 + 持仓汇总
├── portfolio.py      # 总资金 + 当前持仓 -> 具体加/减仓金额建议
├── gui.py            # tkinter 图形界面（推荐入口）
└── fund_analyzer.py  # 命令行入口
```

## 图形界面（推荐）

```bash
python -m funds.gui
```

主要功能页：

1. **信号分析**：管理自选基金清单，批量计算技术指标信号与仓位操作建议；可勾选「含实时涨跌估算」。双击某行查看完整指标明细与仓位建议。
2. **持仓估值**：输入基金代码，按其前 N 大重仓股的实时涨跌加权，估算该基金当日涨跌。
3. **交易记录**：录入每日实际买/卖操作（自动按净值折算份额），自动汇总持仓，用于复盘与后续决策。
4. **资金设置**：设置总仓位金额，查看整体投入/现金占比。
5. **全部基金与回测**：筛选基金，并使用次日可交易净值口径评估历史信号。

> 用户数据（自选、持仓、交易、总资金）保存在 `funds/data/` 下的 JSON 文件中，跨会话保留。

## 命令行

在仓库根目录下执行：

```bash
# 分析默认示例基金（华夏成长、易方达消费、新华优选成长）
python -m funds.fund_analyzer

# 分析指定基金（可一次传入多只）
python -m funds.fund_analyzer 000001 110022 519066
```

## 关于「分析所有基金」

全市场公募基金数量过万，逐一联网分析不现实（耗时以小时计且易触发限流）。
因此本工具采用**自选清单**模式：在「信号分析」页把关注的基金加入清单后批量分析。
如需检索全市场基金代码，可调用 `funds.list_all_funds()`。

也可以在代码中直接调用：

```python
from funds import fetch_fund_nav, compute_indicators, evaluate_signals, fetch_fund_name

nav = fetch_fund_nav("000001")
ind = compute_indicators(nav)
report = evaluate_signals(ind, "000001", fetch_fund_name("000001"))
print(report.to_text())
```

## 评分规则

| 分组 | 权重 | 组成与处理 |
|------|------|------------|
| 趋势 | 0.40 | MA 与 MACD 的平均分 |
| 动量 | 0.25 | 20/60 日收益及阶段回撤 |
| 超买超卖 | 0.35 | RSI、BOLL、KDJ；按当前趋势增强或削弱 |

每个指标输出 `-2 ~ +2` 的子分数，加权求和后乘 5 映射到 `±10` 量纲：

| 综合评分 | 操作建议 |
|----------|----------|
| ≥ +5     | 强烈买入 |
| +2 ~ +5  | 买入     |
| -2 ~ +2  | 观望     |
| -5 ~ -2  | 卖出     |
| ≤ -5     | 强烈卖出 |

## 仓位金额建议（目标仓位法）

设置总仓位金额后，每个信号档位映射一个「单只基金目标占总资金比例」：

| 信号 | 目标仓位 | 说明 |
|------|----------|------|
| 强烈买入 | 25% | 单只上限 30% |
| 买入 | 15% | |
| 观望 | 维持 | 不调整 |
| 卖出 | 5% | 减仓 |
| 强烈卖出 | 0% | 清仓 |

当前持仓市值由交易记录推算（净份额 × 最新净值），
`建议金额 = 目标市值 − 当前市值`，正为加仓、负为减仓，差额小于 100 元视为「维持」。
批量分析时会按总资金约束等比例缩减买入建议，全部建议不会超过可用资金。

## 回测口径

第 `t` 日最终净值公布后生成信号，最早按第 `t+1` 日净值成交，新仓位从
`t+1 -> t+2` 的净值变化开始计收益。默认按每次仓位变化的 0.1% 计交易成本。
信号胜率只统计新出现或发生变化的方向信号，不重复计算连续多日相同信号。
